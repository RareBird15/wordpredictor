# WordPredictor - Дополнение NVDA для упреждающего прогнозирования слов

Дополнение для NVDA, которое отслеживает вводимый текст и предсказывает следующее слово с помощью n-граммного анализа. Предсказания озвучиваются собственным речевым движком NVDA и могут быть приняты с помощью сочетаний клавиш.

## Почему это существует

Существующие инструменты прогнозирования слов, такие как Lightkey Pro AT, создают значительные барьеры для обеспечения доступности при использовании с NVDA:

- Жесты конфликтуют с командами NVDA
- Для прогнозирования в масштабах всей системы требуется щелчок мыши
- Слова искажаются при вставке вместе с NVDA

Это дополнение решает эти проблемы, работая непосредственно в NVDA. Не требуется внешний синтезатор речи, вставка из буфера обмена или мышь. Предсказания произносятся через речевой движок NVDA и вставляются непосредственно через систему ввода с клавиатуры NVDA.

## Возможности

- **Упреждающее предсказание:** После завершения слова (нажатие пробела или знака препинания) NVDA озвучивает до 5 предсказанных следующих слов.
- **Прогнозирование частей слова:** Введите часть слова и нажмите NVDA+Alt+O, чтобы получить предложения, которые дополнят ваш ввод.
- **Звуковое оповещение:** Перед объявлением прогнозов раздаётся короткий звуковой сигнал (настраивается).
- **Выбор с клавиатуры:** Нажмите 1-5, чтобы принять предсказание. Слово будет введено автоматически.
- **Обучение на вашем письме:** N-граммная модель обновляется в реальном времени по мере вашего ввода, изучая вашу лексику и речевые обороты.
- **Постоянное обучение:** Полученные данные сохраняются в пользовательском файле конфигурации NVDA и накапливаются при перезапусках.
- **Предварительное обучение:** Поставляется с n-граммными данными, обученными на опубликованных текстах и распространённых английских словосочетаниях, включая сокращения.
- **Включение/выключение:** Нажмите NVDA+Alt+P, чтобы включить или выключить предсказание.
- **Панель настроек:** Настройте количество предсказаний, звуковой сигнал и обучение в диалоге настроек NVDA.
- **Переназначаемые клавиши:** Все сочетания клавиш отображаются в "Предсказатель Слов" в диалоге жестов ввода NVDA.
- **Работает везде:** Будучи глобальным плагином, предсказание работает в любом приложении, где вы вводите текст.
- **Учитывает особенности терминала:** Автоматически отключает функцию подсказок в терминальных приложениях (Windows Terminal, PowerShell, CMD, WSL, PuTTY и более 25 других). Можно отключить в настройках.
- **Исключение пользовательских приложений:** Добавьте свои собственные приложения, для которых вы не хотите использовать подсказки (MUD-клиенты, редакторы кода, чат-приложения с командами с косой чертой и т. д.) в разделе настроек > предсказатель слов. Одно название приложения на строку.
- **Вставка с учётом пунктуации:** Если вы принимаете предсказание после точки, вопросительного знака или восклицательного знака, автоматически добавляется пробел и первая буква пишется с заглавной буквы. После запятой, точки с запятой или двоеточия добавляется пробел без написания заглавной буквы.

## Назначение Клавиш

| Клавиша | Действие |
|-----|--------|
| От NVDA+Control+1 до NVDA+Control+0 | Принимать прогнозы от 1 до 10 (перехваты только при активных прогнозах) |
| NVDA+Alt+P | Включение/выключение прогнозирования слов |
| NVDA+Alt+O | Запросить прогнозы по требованию (частичные или полные) |
| NVDA+Alt+L | Сохранить обучающие материалы на диск вручную |

Все сочетания клавиш можно переназначить в диалоге жестов ввода NVDA в категории "Предсказатель Слов".

## Установка

1. Загрузите файл последнего выпуска `.nvda-addon` [со страницы выпусков](https://github.com/RareBird15/wordpredictor/releases).
2. Откройте файл в проводнике Windows, чтобы установить его с помощью установщика дополнений NVDA.
3. Перезапустите NVDA.

## Использование

1. Начните вводить текст в любом текстовом поле.
2. При нажатии пробела после слова вы услышите короткий звуковой сигнал, за которым последуют до 5 предсказаний.
3. Нажмите NVDA+Control+1 для принятия первого предсказания, NVDA+Control+2 - для второго и так далее.
4. Предсказанное слово вводится автоматически с пробелом в конце.
5. Для предсказания части слова введите часть слова и нажмите NVDA+Alt+O.
6. Нажмите NVDA+Alt+P, чтобы включить или выключить функцию прогнозирования.
7. Настройте параметры в меню NVDA > Настройки > Предсказатель слов.

## Как это работает

В этом дополнении используются два механизма прогнозирования:

**N-грамная модель (по умолчанию):** Использует анализ биграмм и триграмм с сглаживанием Кнезера-Нея. Быстрая, легковесная и обучается на основе вашего текста в реальном времени. Не требует внешних зависимостей.

**Нейронная сеть LSTM (необязательно):** Небольшая языковая модель, обученная на 20 миллионах токенов современных диалогов из фильмов и сериалов (OpenSubtitles), с контекстным окном из 6 слов. Обеспечивает контекстно-зависимые прогнозы, которые понимают естественные разговорные модели. Включается в Настройках > Прогнозирование слов. Требуется onnxruntime (входящие в комплект DLL-файлы включены или установите через `pip install onnxruntime`).

Оба механизма работают вместе - сначала LSTM предоставляет контекстно-зависимые подсказки, а затем n-граммовая модель заполняет оставшиеся места словами, полученными из вашего собственного текста.

### Подробности N-граммовой модели

- **Биграммы:** Отслеживают, какие слова часто следуют за другими словами (например, "the" -> "system")
- **Триграммы:** Отслеживает, какие слова часто следуют за сочетаниями из двух слов (например, "I am" -> "not")
- **Сглаживание Кнезера-Нея:** Вместо ранжирования предсказаний по частоте встречаемости используется интерполированная вероятность Кнезера-Нея. Это вознаграждает слова, которые встречаются во многих различных контекстах (например, "the", "is", "and"), по сравнению со словами, которые встречаются часто, но только в определённых фразах (например, "York" после "New"). Правильно обрабатывает неизвестные n-граммы, возвращаясь к n-граммам более низкого порядка с скорректированными вероятностями.
- **Трёхуровневая интерполяция:** Вероятность триграммы смешивается с вероятностью биграммы, которая, в свою очередь, смешивается с вероятностью продолжения униграммы. Это означает, что даже слова, никогда не встречавшиеся в точном контексте, всё равно получают вероятность, основанную на том, насколько часто они встречаются в качестве продолжений.
- **Частичное совпадение:** Когда вы вводите часть слова, дополнение ищет во всех n-граммах слова, начинающиеся с введённого вами слова, и ранжирует их по вероятности KN
- **Обучение в реальном времени:** Каждое набранное вами слово обновляет количество n-грамм и производную статистику, поэтому модель адаптируется к вашему стилю письма
- **Постоянное хранение:** Результаты обучения сохраняются в файл `wordPredictor_learned.json` в каталоге конфигурации пользователя NVDA
- **Обратная совместимость:** Используются существующие данные, полученные из версии 1.1.0, без миграции. Сглаживание можно отключить в настройках, чтобы восстановить исходное поведение, основанное на частоте.

Данные n-грамм хранятся в виде JSON-файла и загружаются при запуске. Внешние зависимости Python не требуются.

## Технические подробности

- **Версия NVDA:** Требуется NVDA 2026.1 или выше (Python 3.13, 64-бит)
- **Архитектура:** Глобальный плагин, использующий `event_typedCharacter` для отслеживания ввода
- **Механизм прогнозирования:** Собственная реализация n-грамм, отсутствие зависимости от NLTK во время выполнения
- **Файл данных:** файл JSON размером ~1,6 МБ с подсчётом биграмм и триграмм
- **Конфигурация:** Настройки хранятся в конфигурации NVDA по ключу `wordPredictor`
